\section{Related Work}

\paragraph{Long-term conversational memory benchmarks.}
LoCoMo spans very long conversations with single-hop, multi-hop, temporal, open-domain, and adversarial questions \citep{maharana2024locomo}; LongMemEval adds multi-session reasoning, knowledge updates, and abstention over 500 questions \citep{wu2025longmemeval}; MEME probes evolving entity state, including deletion, cascade, and absence tasks that static retrieval metrics miss \citep{jung2026meme}. MemoryAgentBench frames memory as incremental multi-turn interaction across retrieval, test-time learning, long-range understanding, and selective forgetting \citep{hu2025memoryagentbench}, and BEAM extends to conversations of millions of tokens \citep{tavakoli2026beam}. These benchmarks are complementary, not interchangeable; we label question count, subset, metric, answerer, and judge on every result.

\paragraph{Structured memory systems.}
MemGPT established persistent-memory and context-management baselines \citep{packer2023memgpt}; A-MEM organizes experience as linked atomic notes \citep{xu2025amem}; Mem0 industrializes incremental memory operations with an LLM judge \citep{chhikara2025mem0}. HippoRAG-2 couples a knowledge-graph index with hippocampus-inspired retrieval \citep{gutierrez2025hipporag2}, Cognee builds graph memory through extract--consolidate--load pipelines \citep{markovic2025cognee}, and MIRIX coordinates specialized memory types behind a multi-agent coordinator \citep{wang2025mirix}. All make derived memory a first-class object because compression improves cost and retrieval. We share the need for compact navigation but draw a stronger authority line: a derived node suggests where to look; the source episode remains what the query path must expose and submit.

\paragraph{Long context and retrieval.}
Retrieval-augmented generation answers from selected sources \citep{lewis2020rag}; long-context models keep sources in window but degrade when relevant spans sit far from the window's ends \citep{liu2024lost}. For memory agents this is an architecture axis, not a model property: the official MemoryAgentBench tables show every full-context family failing multi-hop fact consolidation at long range while the same model class solves it at 6K context \citep{hu2025memoryagentbench}. Our rungs deliberately span this axis, and the ladder of \cref{sec:ladder} measures where factual authority can sit without paying recall.

\paragraph{Temporal and graph memory.}
Zep's Graphiti represents entities and relationships in a temporal knowledge graph \citep{rasmussen2025zep}. Deep-Dream also stores relation assertions, timestamps, and concept neighborhoods, but treats the graph as an auditable overlay over documents with an active/incomplete publication boundary: a candidate can be checked against a current source span while historical observations remain addressable.

\paragraph{Evidence and provenance.}
Attribution research evaluates whether generated text carries citations that support its claims \citep{gao2023alce}, but the check is post hoc. Deep-Dream makes it a runtime contract through scope-isolated tools, fresh context per question, read-only access, and evidence-submission validation; the contract is narrower than a semantic fact verifier---it checks reachability, not entailment. Our study asks where the boundary between a useful navigation index and an authoritative source can sit, and evaluates it with end-task QA and retrieval/evidence diagnostics.
