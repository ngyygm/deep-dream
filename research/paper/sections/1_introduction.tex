\section{Introduction}

An agent's memory fails in two ways: it cannot find the past, or it ``finds'' a past that was never said. Memory systems answer with ever-richer derived indexes---compressed facts, summaries, temporal graph edges---and report end-to-end accuracy, but an end-to-end number cannot say where the quality came from: a better index and a better answer path arrive together. This paper asks the question directly: \emph{in long-horizon agent memory, does answer quality come from the derived memory index or from the answer path's access to raw sources---and if the latter, can derived memory be demoted to non-authoritative, auditable navigation without paying for it in retrieval recall or benchmark overall?} The two answers imply opposite architectures: if quality lives in the index, systems should let derived records authorize answers; if it lives in the evidence path, derived memory should navigate---which sources, which versions---while verbatim sources authorize every answer. Prior systems (Mem0, MemGPT, A-MEM, Zep/Graphiti, HippoRAG-2, Cognee) improve index structure and report accuracy gains, but the two contributions are confounded: no prior comparison holds the memory fixed and varies only the answer path.

Deep-Dream runs that comparison on itself. It is a document-first memory server whose derived layer---stable concept families, versioned observations and assertions, relation edges, converged by cluster alignment---is used for navigation only. The winning answer path works in three moves: the overlay \emph{materializes a scope} (which sources, which versions, are relevant); the scope is exposed as a sandbox of verbatim source documents; an agent verifies and answers inside the sandbox with ordinary tools (file reading, \texttt{grep}) and must submit evidence spans it actually read. The submission contract bounds the overlay's failure mode: an overlay error can cause a \emph{missed scope}, never a fabricated fact (\cref{fig:architecture}).

We evaluate three answer paths on identical frozen libraries---single-shot fused retrieval, a read-only memory-tool agent, and the source-sandbox verification agent---and contribute:

\begin{itemize}
    \item \textbf{An answer-path decomposition.} On a 767-question sampled subset of MemoryAgentBench under the official scorer, accuracy rises monotonically with source access---0.324/0.407/0.651---and replicates across two independent engine generations (0.303/0.376/0.669; $n{=}767$, answerer kimi-k3, scorer commit 455306d). Because rungs differ as systems, the ladder upper-bounds the marginal effect of source verification; the single-factor evidence is the ablation below.
    \item \textbf{A measured division of labor between index and evidence path.} A channel ablation bounds the derived overlay's offline retrieval contribution at zero (all channel effects within overlapping 95\% confidence intervals), while the overlay's measured roles are scope materialization, versioning, and deduplication---navigation, not retrieval. Ingest cost falls 46--65\% in calls per document between engine generations with consolidation quality maintained.
    \item \textbf{Cross-system positioning with full caliber disclosure.} On the scorer's judge-free domains the system exceeds published reference points on length-matched cells (SH-QA 92 vs.\ best published 87; DetectiveQA 83.3 vs.\ 77.5), with the larger EventQA and FactConsolidation margins disclosed as length-mismatched (\cref{app:sampling}); subset, answerer, and judge differences are disclosed throughout and no leaderboard subtraction is performed.
\end{itemize}

\Cref{sec:deep-dream,sec:experiments,sec:analysis} develop the memory model, the decomposition, and what the evidence does and does not prove.
