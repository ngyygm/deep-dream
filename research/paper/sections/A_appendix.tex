\subsection{Protocol boundaries}

The original LoCoMo token-F1 track includes 1,986 questions and five categories. The Mem0-compatible track contains 1,540 questions and four categories. LongMemEval-S contains 500 questions over six reported slices in the local summary. MEME's 100 episodes produce heterogeneous task counts (ER/Agg/Tr/Del/Cas/Abs = 100/100/100/100/164/130 after-task checks in the cited run). Raw and real scores are not interchangeable.

\subsection{External comparison protocol}
\label{sec:appendix-protocol}

Mem0's original paper reports LoCoMo category-level F1, BLEU-1, and a binary $J$ in which a GPT-4o-mini judge labels each answer CORRECT or WRONG and the score is the percent judged CORRECT (mean$\pm$std over 10 independent runs). Zep's original paper reports DMR and LongMemEval with GPT-4o-family answerers. Rather than re-run those systems under our protocol, we reproduce their published tables verbatim in Section~\ref{sec:published-baselines} (Tables~\ref{tab:mem0-baselines}--\ref{tab:zep-longmemeval}) as cross-protocol contextual references. The Mem0 deterministic token-overlap metrics (F1, BLEU-1) that were omitted from the main LoCoMo table for space are reproduced verbatim in Table~\ref{tab:mem0-f1-bleu}.

\textbf{The K3-substitution row.} The single Deep-Dream $J$ row placed inside Mem0's $J$ column is produced by running Mem0's exact binary-judge protocol with Kimi-K3 substituted for GPT-4o-mini as \emph{both} the answerer and the judge---the only change is the model. This yields 95.19\% under the same-model K3 judge (97.38/93.62/80.21/95.33 S/M/O/T) and 94.22\% under an independent Qwen3.7-plus cross-judge on the same K3 answers (96.91/92.91/77.08/93.46; cross-judge agreement 98.51\%). Two differences from Mem0's published $J$ are admitted: it is a single run rather than a 10-run mean$\pm$std, and the model is Kimi-K3 rather than GPT-4o-mini. We additionally disclose an integrity caveat: the run manifest carries \texttt{diagnostic\_override=\{kind:legacy-missing-runtime-code-fingerprint, formal\_claim\_allowed:false\}}, because 1{,}529 of the 1{,}540 answer rows originate from a legacy source run (\texttt{locomo-full-quality-v1}) that predates runtime-code fingerprinting. The answers themselves are unchanged (\texttt{answer\_rows\_unchanged=true}, source-and-diagnostic answer SHA-256 76af5772) and the per-item JSONL does carry \texttt{runtime\_code\_sha256} on all 2{,}063 rows, but we report the 95.19\% as a diagnostic cross-judge result rather than a fingerprint-complete formal result. A fresh, fingerprint-complete K3-as-answerer pass would remove this caveat and is the one remaining step to a fully formal $J$ entry; the present number is sufficient to sit beside Mem0's published $J$ in the same column under the same metric.

A stricter controlled comparison---freezing the same answer model, judge model, prompt, temperature, evidence budget, dataset revision, and Graphiti/Zep implementation commit---remains the only path to a shared leaderboard, but it is no longer a submission hard gate now that the published numbers are cited directly.
