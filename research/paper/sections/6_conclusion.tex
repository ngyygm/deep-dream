\section{Conclusion}
\label{sec:conclusion}

This paper asked where answer quality lives in long-horizon agent memory---in the derived index or in the answer path's access to raw sources---and built Deep-Dream to run the comparison. The answer the data supports: in the evidence path. Extending the answer path from single-shot retrieval through memory-tool agency to sandbox-verified reading raises official-scorer accuracy monotonically from 0.324 to 0.651 and replicates across two engine generations; the overlay's retrieval channels are recall-null within overlapping confidence intervals; its online selection value is not yet separately priced, and it stays as non-authoritative navigation with ingest cost down 46--65\% in calls per document. Because the evidence gate requires answers to cite spans the agent actually read, an overlay error can cause a missed scope but never a fabricated fact.

We do not claim single-factor causal isolation, a same-model full-context anchor, a full-set benchmark run, or solved deletion and test-time learning. But the ladder's replication and its agreement with the ablations make one architecture lesson hard to avoid---let verbatim sources authorize answers, and let derived memory only decide where to look.
