\section{Conclusion}
\label{sec:conclusion}

Long-term memory has two linked problems: preserving a growing record as entities and facts change, and finding only the evidence needed for a question within a finite context window. Deep-Dream addresses storage by keeping document spans factual while concepts, relations, observations, versions, and candidate identities provide revisable access structures. It addresses reading by letting the agent follow those structures to earlier or later passages and stop when the evidence is sufficient.

Each component has a clear role: the graph narrows the search space, the source span preserves the wording and values, and the agent chooses whether another document, relation, or version is needed. The MAB results therefore compare complete reading paths. The write results show that delayed alignment with batched processing lowers ingest cost and duplicate-name families, while the full-context reference remains strongest when its window fits. The MEME result shows why retaining history does not by itself specify when an old fact should be suppressed.

The recorded trace makes this separation concrete: concepts and relations locate candidates, while source spans supply the values. Our contribution is a memory design in which storage and reading can be improved and audited separately, with explicit interfaces for future identity decisions, current-versus-historical queries, entailment checks, and deletion rules.
