Long-horizon memory for language-model agents derives compact indexes---facts, summaries, graph edges---whose contribution to final answer quality is rarely separated from the answer path's access to raw sources. We decompose the two. Deep-Dream is a document-first memory server that demotes all derived structure to non-authoritative navigation: concept overlays materialize \emph{which} sources are in scope, a sandbox exposes the verbatim sources to a verification agent, and an evidence gate requires answers to cite spans the agent actually read, so an overlay error can cause a missed scope but never a fabricated fact.
On a 767-question sampled subset of MemoryAgentBench under the official scorer, holding engine, model, and frozen libraries fixed, extending the answer path from single-shot retrieval through memory-tool agency to sandbox-verified reading raises overall accuracy monotonically from 0.324 to 0.651, and the same ladder replicates across two independent engine generations (0.303/0.376/0.669). A channel ablation bounds the derived overlay's offline retrieval contribution at zero within overlapping confidence intervals, locating quality in the evidence path; the overlay is retained as non-authoritative navigation, with ingest cost falling 46--65\% in calls per document between engine generations and consolidation quality maintained (its online selection value not yet separately priced). On the scorer's judge-free domains the system exceeds published reference points by wide margins, with all caliber differences disclosed.
