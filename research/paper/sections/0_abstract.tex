Long-term memory for language-model agents should answer two different questions: can a system find a relevant past event, and can it show which still-valid source supports the answer? Existing systems often optimize the first question by storing compressed facts, summaries, or graph edges, which can make retrieval efficient but can also obscure provenance and state changes. We present Deep-Dream, a document-first memory server that treats derived concepts and relations as an auditable navigation overlay rather than as an independent source of truth. Deep-Dream combines heading-aware episodes, conservative concept alignment, lexical--semantic--graph candidate generation, source-span expansion, and a scope-checked evidence-submission interface. The interface guarantees that submitted evidence identifiers were actually exposed to the agent in the active conversation scope; it does not assume that identifier validity alone proves semantic entailment.

Across explicitly labeled local protocols, Deep-Dream reaches 93.18\% on the 1,540-question Mem0-compatible LoCoMo setting under a Qwen3.7 judge (93.57\% under a Kimi-K3 cross-judge) and 84.60\% on the 500-question LongMemEval-S setting under a Qwen3.7 cross-judge. On a 105-case prior-error diagnostic, holding lexical--semantic candidates fixed and adding two neighboring turns increases evidence recall-all by 20.95 points for 16.84\% more payload. We separate these protocol-aligned results from published Mem0 and Zep numbers, report a failed depth replay and a 0\% MEME deletion result, and identify the controlled provenance, update, and cross-system experiments required for a submission-level claim.
