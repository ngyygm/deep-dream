\section{Analysis and Limitations}
\label{sec:analysis}

The scientific problem is how to make a growing record of experience searchable and trustworthy when a query can read only part of it. Summary-only memory loses wording and qualifications at write time; graph-only memory can mistake derived links for facts; fixed full-context prompting pays for every document and eventually exceeds the window. Deep-Dream separates three responsibilities: concepts and relations locate candidates, observations and source spans authorize facts, and the agent decides how much evidence to open.

This separation changes what a graph should be judged on. The graph need not contain a complete answer, and graph channels need not improve offline top-ten recall by themselves. Their role is to provide a compact route to document groups, versions, and related episodes before source reading. The channel replay supports this interpretation: the graph is an address layer, not a second fact store. MAB gains on questions that join mentions or check updates therefore support navigation plus source reading; LoCoMo adds the complementary case in which relation paths connect episodes while linked text remains the authority.

Progressive alignment addresses a different scientific question: how should identity uncertainty be handled when the first mention is ambiguous? Keeping two candidate families preserves a recoverable uncertainty; later observations can redirect pointers and merge compatible families without rewriting the observations that caused the split. An early wrong merge contaminates one address with two histories and is harder to undo. Align+ is therefore a revision policy, not merely a faster extractor. Its lower call counts and fewer duplicate families are consistent with less repeated work, but bundled concurrency and runtime changes prevent a component-level causal claim.

The temporal principle gives long-term memory a precise state axis. Processing/observation time orders versions; event dates remain content in the observations. New information adds a version or pointer while leaving the old span available, so an earlier statement and a later correction remain jointly searchable. This preserves the history needed to explain change, but it does not specify which observations should be suppressed after deletion. MEME exposes that missing operation: temporal revision and deletion are distinct capabilities.

At read time, the information-theoretic model predicts adaptive allocation rather than one fixed summary size (\cref{sec:information-view}). The address term in \cref{eq:two-rate-code} is cheap and lossy enough to navigate; the source term supplies the wording needed for the answer. A local question can stop early, whereas a multi-hop, update, or conflict question should expand relations and read more spans. The answer decomposition in \cref{eq:answer-decomposition} separates failure to find a span from failure to verify it. Current results support the value of source reading and revision-aware writing, but they do not measure entropy reduction directly.

The evidence has limits. MAB paths are complete-system comparisons, not single-component interventions; LongMemEval and LRU subsets are small; and published cross-system rows use different models, judges, and subsets. The equations describe intended information flow, not measured gains or an optimality proof. The citation gate confirms that an opened span was returned by a tool, not that it entails the answer. Future work should measure entity uncertainty, merge contamination, accuracy under a fixed read budget, deletion and as-of-time behavior, conflict handling, and confidence calibration.
