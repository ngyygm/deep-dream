\section{Analysis and Limitations}
\label{sec:analysis}

The main claim is about calibration between storage and reading. A source span is a preserved observation; an identity family, relation, or version is an inferred access structure; a retrieved passage is what the agent elected to inspect. Keeping these categories separate makes revision possible but does not ensure that an identity is correct or that the inspected passage entails the answer. The source gate validates provenance, not identity or entailment.

The storage choice matters before any query is known. A summary-only store compresses the record in advance, so a later question may need a qualifier, an earlier state, or the original wording that the summary omitted. Deep-Dream keeps that source observation and uses the graph only to make it addressable. A current value therefore remains linked to the observations that produced it, rather than replacing them.

Delayed alignment makes this representation revisable. An early merge can place two people with the same name behind one address and contaminate both histories; a temporary split only adds candidates and can later be corrected by redirecting links. This is why the storage result should be read as a cost and revision result, not as proof that the current identity labels are already correct. Version links preserve how a current value was reached: processing time orders stored states, while dates mentioned in the source remain part of the observation. A query can therefore ask for the latest value or an earlier value without rewriting the record.

Align+ reduces ingest calls by 46--65\% while combining delayed alignment, batching, and parallel processing. Same-name families fall from 340 to 124 on MemoryAgentBench and 482 to 99 on LongMemEval. Duplicate-name proxies are not identity labels, and the paired quality interval is $-7$ to $+13$ points. MCC and FC-MH each change by 3 points (95\% interval $-7$ to $+13$), supporting a construction trade-off rather than a measured identity gain. The entropy argument is conditional on a fixed target and retained predecessor state.

The MAB ladder compares fixed retrieval, memory tools, and source reading at 33.3\%, 40.0\%, and 71.0\% with Kimi-K3 on 1,074 questions. The complete paths differ in tools, source access, iteration, evidence handling, and budgets, so they do not isolate an identity or graph effect. Source reading reaches 70.8\% against full context's 78.7\% on 614 matched questions; 460 questions exceed the reference budget. The offline graph ablation is null. A smaller context can still cost more if the agent repeatedly searches, and provenance checks do not solve stopping or answer support.

MEME records 0\% deletion accuracy on 100 deletion checks within 694 after-task checks, with cascade 46.34\% and absence 59.23\%. The path lacks target tombstones and propagated suppression. LongMemEval-S reaches 84.6\% with Qwen3.7-plus as both answerer and judge under a distinct protocol. LoCoMo's 95.19\% and 94.22\% are legacy single-run diagnostics because 1,529 of 1,540 rows predate runtime-code fingerprinting. These results call for direct identity labels, entailment checks, and resource-matched reading experiments.

\paragraph{What remains unmeasured.} A provenance-checked span can still be irrelevant, and a correctly linked identity can still require another document. The current runs do not provide labeled identity decisions, entailment annotations, or resource-matched stopping curves. Nor does the deletion result test a complete suppression design. These gaps define direct follow-up evaluations: label candidate merges, hold calls and tokens fixed across read policies, and score current and historical queries separately.
