# Mem0 论文：benchmark 与原始结果

来源： [Mem0 论文（arXiv:2504.19413）](https://arxiv.org/abs/2504.19413)；表格正文见 [HTML 版本](https://ar5iv.labs.arxiv.org/html/2504.19413)。

## 论文实际测评的 benchmark

原始论文只在 **LoCoMo** 上做主实验：10 段长对话，报告四类问题——Single-hop、Multi-hop、Open-domain、Temporal；LoCoMo 的 Adversarial 类没有进入这张主表。回答由 GPT-4o-mini 生成，使用 F1、BLEU-1 和 GPT-4o-mini judge 的综合分数 `J`，并对 10 次运行取均值/标准差。

## 与本项目的对照

本项目已经有一组更适合横向比较的 **LoCoMo 1540 题 exact protocol** 结果：

| 结果 | 项目分数 | 说明 |
|---|---:|---|
| Qwen3.7 judge | **93.18%** (1435/1540) | 使用 Mem0 benchmark 的 1540 题/类别协议；本地 judge 与 Mem0 论文不同 |
| Kimi-K3 judge | **93.57%** (1441/1540) | 同一项目输出的交叉 judge |
| 原项目 quality-v1 token-F1 | **64.99** | 1986 题旧协议，不应与上面百分比直接混排 |

因此可以说：**题集和类别协议层面可以和 Mem0 比，但项目的 93.18%/93.57% 是二值 judge accuracy，论文的 `J` 是 0–100 的 rubric 分数，不能直接做数值高低结论**。此外 answer model、judge、prompt、memory backend 和评测实现也不完全相同，所以不是严格 head-to-head。要形成可发表的严格比较，应在同一 Mem0 官方 harness 中固定模型、judge、temperature、索引和 prompt 后重跑 Mem0 与本项目。

## 论文之外的 Mem0 当前 benchmark 页面

Mem0 的公开 benchmark 仓库还报告了更新后的 LoCoMo **92.5% (1425/1540)**、LongMemEval top-200 **94.4%**、top-50 **94.8%**，以及 BEAM 1M/10M **64.1/48.6**。这些是当前仓库/平台结果，不属于上面原始论文 Table 1，需单独标注。见 [mem0ai/memory-benchmarks](https://github.com/mem0ai/memory-benchmarks)。
