## Core scientific question (the reframe)

**Old framing (8/13):** "Which part of the memory is allowed to authorize an answer?" — a system-positioning paper whose strongest numbers (LoCoMo cross-judge) could not be compared across systems, leaving the contribution mostly architectural plus evaluative discipline.

**New framing:** the paper can now answer a sharper, falsifiable question:

> In long-horizon agent memory, does answer quality come from the derived memory index (facts, summaries, graph edges) or from the answer path's access to raw sources — and if the latter, can derived memory be demoted to non-authoritative, auditable navigation without paying for it in offline retrieval recall or benchmark overall?

**Answer the paper gives:** the evidence path carries the quality. Holding engine, model, frozen library, and scorer fixed, each rung of source access strictly extends the answer path toward verbatim sources, and accuracy rises monotonically at every rung in two independent engine generations (MAB: 0.324→0.407→0.651 and 0.303→0.376→0.670, n=767, official scorer), echoed on full-ingest LME (0.72→0.926, n=25/27, small-sample disclosed). The derived overlay's retrieval channels are recall-null within tight bounds (X7: all channel effects inside overlapping 95% CIs), so the overlay's measured roles are scope materialization, versioning, and deduplication — navigation, not retrieval. Because answers must cite spans the agent actually read, auditability is a by-construction property of the winning path rather than an add-on, and an overlay error can cause a *missed scope*, never a fabricated fact. On the scorer's judge-free domains the system exceeds published reference points by wide margins (FC-MH 70 vs best published 7) with all caliber differences disclosed.

**Wording discipline (reviewer W1/W3):** the ladder is an **answer-path decomposition, not a mechanism isolation** — rungs also differ in answerer arrangement, prompt, and compute, so the strongest permitted verb is "is consistent with"; "isolates"/"shows that quality comes from" are prohibited. "Disposable" is prohibited; the correct claim is "non-authoritative, demoted to navigation, failure mode = omission not fabrication."

This reframing absorbs the old auditability story as a *consequence* of the evidence-path design, uses the strongest new numbers where they are strongest, and turns the X7 null from an embarrassment into half the mechanism result (index side null, evidence side positive).

## One-sentence contribution

Holding engine, model, and frozen libraries fixed, extending the answer path's access to verbatim sources — from single-shot retrieval through memory-tool agency to sandbox-verified reading — raises MemoryAgentBench overall monotonically from 0.324 to 0.651 (n=767, official scorer) in two independent engine generations, while a channel ablation bounds the derived overlay's offline retrieval contribution at zero within overlapping confidence intervals — supporting a design in which derived memory serves as non-authoritative, auditable navigation and the system nonetheless exceeds published reference points on the benchmark's judge-free consolidation domains.

## Structure (section by section)

### §0 Abstract (~200 words, five-sentence formula; per reviewer W4)

1. **What**: we decompose where long-horizon memory quality comes from: the derived index or the answer path's access to raw sources.
2. **Why hard**: memory systems invest in derived indexes whose contribution to final accuracy is rarely separated from the answer path; provenance and auditability are usually traded against quality.
3. **How**: a document-first memory server with versioned concept overlays used for navigation and scope materialization only; three answer paths evaluated on identical frozen libraries; evidence submission restricted to spans the agent actually read.
4. **Evidence**: monotone ladder 0.324→0.407→0.651 on MAB (n=767, official scorer, replicated across two engine generations); channel ablation bounds the overlay's offline retrieval contribution at zero within overlapping CIs; ingest cost −46%…−65% calls/doc.
5. **Remember**: on the scorer's judge-free consolidation domains the system exceeds published reference points by wide margins (per-domain numbers in body), with all caliber differences disclosed. *(No "order of magnitude", no "+10 pp adjusted" in the abstract — those carry caveats that cannot fit.)*

### §1 Introduction (~1.3 pages)

- **Hook**: an agent's memory fails in two different ways — it cannot find the past, or it "finds" a past that was never said. Systems answer by building ever-richer derived indexes; we ask whether the index is where quality actually comes from.
- **Gap**: prior systems (Mem0, Zep/Graphiti, MemGPT, HippoRAG-2) improve index structure and report end-to-end accuracy, but index contribution and answer-path contribution are confounded; no comparison of answer paths on identical memory exists; provenance usually costs accuracy or is bolted on.
- **Approach**: Deep-Dream keeps raw sources as the only evidence layer and demotes all derived structure to non-authoritative navigation: scope materialization gives the agent a verifiable sandbox of sources; answers must cite spans actually read; an overlay error can cause a missed scope, never a fabricated fact.
- **Contributions** (3 bullets):
  1. A source-grounded memory architecture with versioned concept overlays as non-authoritative navigation (conservative alignment + cluster convergence; ingest calls/doc −65%/−46% v1→v2 paired, duplicate families eliminated).
  2. An answer-path decomposition on identical frozen libraries: single-shot retrieval / memory-tool agent / source-sandbox verification score 0.324/0.407/0.651 on MAB (n=767, official scorer), **monotone at every rung in two independent engine generations** (0.303/0.376/0.670); a channel ablation bounds the overlay's offline retrieval contribution at zero — the evidence path carries the quality.
  3. Cross-system positioning with full caliber disclosure: judge-free consolidation domains far above published reference points (FC-MH 70 vs 7); LoCoMo-1540 under Mem0's exact J protocol as labeled context.
- **Results preview**: the ladder with v1 replication inline, per-domain judge-free numbers, n and scorer named.
- **Hero figure**: Fig. 1 (reworked) — substrate/overlay/sandbox architecture with the three answer paths traced as distinct evidence flows; caption states the ladder result and that the ladder is a systems comparison.

2. **Long-horizon benchmarks**: LoCoMo, LongMemEval, MEME, MemoryAgentBench — what each measures; MAB's four domains map onto our claims (AR=retrieval, FC=consolidation, TTL=test-time learning, LRU=long-range understanding).
